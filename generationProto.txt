# 1. Инициализация Go модуля
# Создает файл go.mod с именем проекта
go mod init grpc-user-api

# 2. Установка основных зависимостей
# Скачивает библиотеку gRPC для Go (Чтобы код мог использовать gRPC)
go get google.golang.org/grpc

# 3. Установка библиотеки для работы с protobuf
go get google.golang.org/protobuf

# 4. Установка плагинов для генерации кода
# Эти плагины нужны, чтобы protoc умел генерировать Go-код (Чтобы protoc генерировал Go-код для данных, сервисов)
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest

#5. ГЕНЕРАЦИЯ КОДА ИЗ PROTO-ФАЙЛА
# Генерируем код
protoc --go_out=. --go_opt=paths=source_relative \
    --go-grpc_out=. --go-grpc_opt=paths=source_relative \
    proto/user.proto

#В папке proto/ появятся два новых файла:
  -user.pb.go — содержит Go-структуры для всех ваших сообщений
  -user_grpc.pb.go — содержит интерфейсы для сервера и клиента

#Флаг	Что делает
--go_out=.	Генерирует код для данных (структуры) в текущую папку
--go_opt=paths=source_relative	Создает файлы рядом с .proto файлом
--go-grpc_out=.	Генерирует код для gRPC (сервер и клиент) в текущую папку
--go-grpc_opt=paths=source_relative	Создает файлы рядом с .proto файлом
--proto/user.proto	Путь к файлу

мапперы нужны для преобразования доменных сущностей в proto структуры 







1. Клиент отправляет CreateOrderRequest (PROTO)
   ↓
2. gRPC сервер принимает запрос
   ↓
3. [МАППЕР] FromProtoCreateOrder()
   Proto → Domain
   ↓
4. Бизнес-логика работает с domain.Order
   ↓
5. Репозиторий сохраняет domain.Order в БД
   ↓
6. БД сохраняет данные
   ↓
7. Репозиторий возвращает domain.Order (или ошибку)
   ↓
8. Бизнес-логика создает ответ
   ↓
9. [МАППЕР] ToProtoCreateOrderResponse()
   Domain → Proto
   ↓
10. gRPC сервер отправляет CreateOrderResponse (PROTO)
   ↓
11. Клиент получает ответ







1. Клиент отправляет GetOrderStatusRequest (PROTO)
   ↓
2. gRPC сервер принимает запрос
   ↓
3. Бизнес-логика вызывает репозиторий
   ↓
4. Репозиторий получает domain.Order из БД
   ↓
5. [МАППЕР] ToProtoOrder()
   Domain → Proto
   ↓
6. gRPC сервер отправляет GetOrderStatusResponse (PROTO)
   ↓
7. Клиент получает ответ
